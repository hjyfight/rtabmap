# 3001接口规范与时间同步验证

展开和收起状态按分支、处理步骤及区块标识保留。自动样本更新、侧栏刷新和切换步骤不会重置已展开的内容；同一标签页重新加载时恢复此前选择。浏览器存储不可用时使用当前页面的内存状态。

流程页的“时间与接口”默认突出50 ms同步限值、当前最大配对时间差和配对核查结果，以柱状图展示各组时间差。逐帧时间戳、时间轴、运行容差、平均/P95统计及偏移测量信息集中收进展开记录。接口规范和批次核查继续提供。

输入字段在选中RGB、RGB-D、NIR、LiDAR和声学窗口时保存。每份特征归档通过分支、会话、序号、模型哈希及关联时间与结果对应；中间特征核对实际NPY头中的形状和类型。完整模型特征与保存的末帧张量形状分别展示。旧归档没有输入字段时标记缺失，不以最新输入快照补填。

声学记录保留采集通道和模型单通道转换。重叠采集窗口按实际覆盖关系记录其对选中PCM的采样区间贡献。

## 同步指标

`config/research_verification.json`保存要求来源、50 ms通用同步限值和50 ms配对核查门限。实际运行配对容差从每个样本的归档读取，保持原推理配置。

配对统计显示组数、平均、P95、最大时间差和超门限组数。配对门限核查不能代替同步精度测量。SSH往返不确定度或接收延迟估计作为时间质量记录展示，不能证明真实曝光、扫描或ADC时间同步。


## 接入真实同步测量记录

实际实验完成后，`logs/research/sync_measurements.json`可保存下述格式。记录必须对应同一分支、会话和序号，注明测量方法及证据，并覆盖采集时间；界面按最大误差加测量不确定度与限值比较。缺少记录、身份不匹配或数据不完整时保持待验证。

```json
{
  "schema": "research_sync_measurements/1",
  "records": [
    {
      "task": "rgbnir",
      "session_id": "填写实际会话",
      "sequence": 0,
      "method": "填写实际共同时间参考或同步事件测量方法",
      "evidence": "填写原始测量文件或证据编号",
      "covers_acquisition_time": true,
      "max_error_ms": 0,
      "uncertainty_ms": 0
    }
  ]
}
```

此格式示例不是实测数据，误差及不确定度应替换为真实记录。测量文件或规范变更会更新归档显示，即使模型没有产生新序号。

融合结果采用当前真实图片进行定性对照；界面不自动生成定量精度或合格结论。
