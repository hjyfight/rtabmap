**RGB/NIR固定特征融合：原理、证据与专家说明（2026-11-23）**

本文对应3001的“YOLOv8-seg · RGB 90% + NIR 10%”实验支路。识别能力来自完整COCO80预训练模型；近红外用于改变输入分割头的多尺度特征。当前可以证明融合计算存在，尚未证明融合识别精度优于RGB。

**可用于口头说明的表述**

> 我们采用完整预训练YOLOv8实例分割模型作为识别基础。RGB和近红外经过时间配对与空间配准后，共用冻结骨干，在P3、P4、P5三个尺度提取同维度特征。近红外特征先做RMS幅值匹配，再在有效配准位置以10%的固定权重与RGB特征融合，融合结果进入原有neck和分割头。识别类别来自模型已有的训练知识，近红外可能补充物体轮廓和纹理线索，改变候选分数及掩膜。当前属于固定参数的跨模态特征融合实验，是否提高正确检出率和分割精度，需要同帧、同真值的对照试验确认。

**实际计算流程**

1. 深度、相机内参和相机间变换用于NIR到RGB的几何配准，并选择时间匹配的真实输入。深度在这里提供配准几何，没有作为独立深度特征分支送入YOLO。
2. RGB和配准后的mono8 NIR采用相同的缩放与填充。NIR复制成三通道以满足原骨干的输入格式，两路分别通过同一个冻结骨干。
3. 从骨干层4、6、9取得P3/P4/P5特征。对应特征的空间尺寸、通道数和使用的滤波器一致；这提供融合所需的表示和尺度条件，不等于已证明NIR与RGB的语义对应正确。
4. 对每个尺度，在有效位置计算两路特征RMS。令

   `s = clip(RMS(F_RGB) / (RMS(F_NIR) + ε), 0.25, 4)`

   `α = 0.1 × M`

   `F_fused = (1 − α) × F_RGB + α × s × F_NIR`

   其中M是该尺度的有效配准掩码。因此有效位置采用90/10融合，无效位置的融合输入特征保留RGB。下游卷积、框选择和NMS可能传播邻域影响，不能据此承诺无效区域的最终预测完全不变。
5. 融合特征在原neck读取对应尺度时进入计算；后续分类、框回归和掩膜解码使用原有预训练参数。当前默认候选置信度门槛为0.35，NMS框IoU门槛为0.5。

源码依据：`src/rtabmap_research/rgbnir.py`的模型初始化、P3/P4/P5 hook、`forward_tensors()`、`decode()`和`infer()`。

**为什么融合以后仍能输出“椅子”**

- COCO80原本包含chair类别，骨干和分割头已经学到与椅子有关的视觉模式，融合没有新增类别。
- 原模型结构、参数和特征维度保留，分割头仍可以计算融合特征的类别分数及掩膜。
- RGB占主要分量，NIR提供同一位置的另一种波段观测。同一物体在两种波段可能具有不同的反射、对比度和纹理，因而有机会补充RGB中较弱的线索。
- 特征变化经过非线性的neck/head，会改变类别分数、框和掩膜。某个候选可能越过置信度门槛，也可能出现误检、重复或掩膜退化；具体原因需检查对应真实帧的分数与特征，不能仅凭截图断言。

NIR输入没有经过本任务的专门训练。复制三通道只解决输入形状，不能恢复颜色，也不能保证跨波段语义对齐。RMS匹配控制数值幅度，不是语义校准。90/10是当前工程试验参数，尚不是经验证的最优权重。

**常见追问及回答口径**

| 专家问题 | 当前可支持的回答 |
| --- | --- |
| 没有重新训练，为什么还能识别？ | 复用已有预训练识别能力，在原特征维度内进行受控融合；可运行和有类别输出已验证，任务效果仍待评价。 |
| 同一个骨干是否等于语义已经对齐？ | 它保证滤波器和通道组织一致；跨波段语义正确性还需验证。 |
| 为什么选90/10？ | 当前以RGB为主的固定实验设置；应通过验证集权重消融选择参数，再在独立测试集报告效果。 |
| 多检出一个是否说明更准确？ | 需要人工真值确认新增实例是否正确，并同时统计漏检、误检、重复及掩膜质量。 |
| 能否宣称低光照下必然更好？ | 只能提出NIR可能提供补充观测的机制假设；必须用真实低照度分组试验检验。 |
| 是否证明融合比最佳单模态更好？ | 尚未证明。目前有同帧RGB对照，仍需要规定的单模态基线、人工标注和统一评价口径。 |

**后续最小验证方案（待执行）**

1. 保存同步的原始RGB/NIR/深度、内外参、时间戳、有效掩码、模型版本和P3/P4/P5融合前后特征。
2. 固定模型、输入分辨率、类别和候选门槛，比较RGB基线、共享骨干NIR单模态试验以及不同融合权重。明确NIR复用的是RGB预训练权重。
3. 对截图中的候选及一组连续真实帧做人工实例标注，统计Precision、Recall、检测mAP与mask AP/IoU；同时记录重复检测和漏检。
4. 分别报告正常光照、低照度、遮挡或反光工况的结果；参数选择与最终评价使用不同场景组，避免用测试集调权重。
5. 验证实现存在、精度改善、时间同步及完整处理周期分别出结论；未完成的项保留未验证状态。
