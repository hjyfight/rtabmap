# 三维语义标签显示

三维地图右下角“物体标签”可选“稳定标签 / 全部标签 / 隐藏标签”。默认稳定标签，选择按面板保存。旧设置中的 `declutter` 自动按稳定标签解释。

稳定标签按对象 ID 显示具体预测类别；“其他物品 / 其他家具 / 其他结构”等泛化类别显示为小圆点，悬停可看预测类别和对象 ID。“全部标签”将这些圆点恢复为文字。字体固定为屏幕像素，字号设置限制在 10–16 px，避免旧布局的六倍标签倍率和透视距离引起巨大的文字。

旋转、缩放只改变标签锚点的投影位置，不重新分组、不改变类别、不折叠标签、不显示 `+N`。超出视野或移到相机背后的标签仍由正常投影处理；新检测、后端类别更新、对象删除也仍正常生效。当前没有屏幕文字自动避让，具体类别很多时仍可能互相覆盖，可以放大查看或切换隐藏标签。

显示策略只作用于 `/miti/semantic_markers` 中 `miti/<object_id>/label` 文字；保留物体位置点、数据库、ROS 对象和其他地图标记。每个三维视图独立选择显示模式。它不负责确认多个记录是否属于同一个物品，也不修正模型的类别误判。

## 2026-11-10 排查

只读采样报告：`logs/miti/semantic_labels_audit_20261110.json`。

- `/semantic/objects` 和 `/miti/semantic_markers` 各 1 个发布者。
- 当时有 33 条对象记录、31 个 ADD 文字标记，文字标记的 `(ns,id)` 全部唯一。
- 电视记录 #5 附近有“其他物品”#27（中心相距约 0.064 m）和 #10（约 0.152 m）。它们有历史同帧分离证据；#10 和 #27 当前保留的观察中也有 10 个共同关键帧。
- 这表明仅用“同名”或“中心接近”合并不可靠：分割碎片、类别波动、历史记录和相邻真实物品都可能存在。当前修复处理文字重叠，物理实例去重需要进一步的图像掩膜、几何和时序证据。

随后用户反馈“电视 +5、盒子 +3”，旋转时名称/数量跳变、突然显隐。这由刚加入的屏幕重叠算法触发：它每 100 ms 按文字包围框选代表，位于不同深度的物品也可能折叠在一起。因此撤掉该算法及 DOM 可见性定时器，使用上述稳定显示方式。

## 验证

`tests/test_miti_semantic_labels.js` 覆盖电视/盒子周围多条记录、视角输入变化时身份/文字稳定、显示模式恢复、多视图隔离、单对象更新/删除和字号限制。`tests/test_miti_frontend_install.py` 验证实际 MITI bundle 的路由与作用域，并从安装后 bundle 提取组件运行同一组渲染回归测试。这不替代真实浏览器中的 WebGL 旋转检查。
