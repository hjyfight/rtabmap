# 三维语义标签显示

三维地图右下角“物体标签”可选“稳定标签（单物体） / 全部标签 / 隐藏标签”。默认稳定标签，选择按面板保存。旧设置中的 `stable` 和 `declutter` 均继续使用稳定显示。

稳定标签按三维物体分组，每组显示一个预测类别。跨帧重复记录需具有相近中心、相似体积和充分重叠的三维范围；保留在同一关键帧中分别观测到的独立物体，也保留桌上的小物体等大小明显不同的嵌套物体。分组要求每对成员相容，避免沿近邻链把一排物体合成一个。已建立的分组使用几何滞后门限，代表类别按独立观测和置信度选择，并设置 25% 的切换余量。

“其他物品 / 其他家具 / 其他结构”等泛化类别，以及“室内设计 / 娱乐室 / 院子 / 武术馆 / 汽车制造 / 赛道”等场景或抽象预测，在物体模式中不生成文字、占位圆点或底框。“全部标签”可查看这些有效的原始预测名称，仍使用相同的三维物体分组。空白、不可见字符、仅符号或未知名称在所有模式中均不生成标签。具体物体类别继续显示中文名称，两个独立同类物体各有自己的标签。字体固定为屏幕像素，字号设置限制在 10–16 px，避免旧布局的六倍标签倍率和透视距离引起巨大的文字。

旋转、缩放只改变标签锚点的投影位置，不重新分组、不改变类别、不折叠标签、不显示 `+N`。超出视野或移到相机背后的标签仍由正常投影处理；新检测、后端类别更新、对象删除也仍正常生效。当前没有屏幕文字自动避让，具体类别很多时仍可能互相覆盖，可以放大查看或切换隐藏标签。

分组发生在地图展示适配器中，合并对应的位置点和 `miti/<object_id>/label` 文字，并持续发送被替代标记的定向删除。保留数据库、原始 `/semantic/objects` 和其他地图标记；每个三维视图独立选择显示模式。类别仍来自模型，去重不修正模型误判。

网页仅绘制物体名称，不再绘制 `miti/<object_id>/point` 的独立位置球。这些位置球此前在文字被隐藏后仍存在，投影后会像空标签的小块。过滤发生在原生标记几何渲染入口，所有标签模式均生效；地图点云、墙面、导航节点和其他命名空间的球体照常显示。原始位置数据仍可供其他客户端使用。

新语义节点通过可选 `/semantic/object_geometry` String JSON 发布当前地图/时期/坐标系下的三维范围，不改变已有 `SemanticMap` 消息格式。仍在运行的旧语义节点可通过配对语义数据库兼容：显示适配器最多每两秒只读一次当前时期，使用自己已知的优化图旋转范围。未知图位姿不能用于估算范围。真实范围与已知位置一起保存在 `MITI_STATE_DIR/semantic_display.json`，显示重载时保留历史标签；不同地图或时期不会复用。无范围时保留原有的保守近距离规则。

2026-11-17 实机复核中，服务台/办公桌的历史记录合并为一个显示身份；两把相距约一米的椅子分别保留。固定输入回放由 29 条记录生成 26 个标签，实时检查中的 30 条原始记录生成 27 个标签。原始建图和 RGB/NIR 融合均未重启。记录见 [固定输入回放](../logs/semantic_validation/object_label_replay.json)、[实时检查](../logs/semantic_validation/object_label_after.json)。

## 2026-11-10 排查

只读采样报告：`logs/miti/semantic_labels_audit_20261110.json`。

- `/semantic/objects` 和 `/miti/semantic_markers` 各 1 个发布者。
- 当时有 33 条对象记录、31 个 ADD 文字标记，文字标记的 `(ns,id)` 全部唯一。
- 电视记录 #5 附近有“其他物品”#27（中心相距约 0.064 m）和 #10（约 0.152 m）。它们有历史同帧分离证据；#10 和 #27 当前保留的观察中也有 10 个共同关键帧。
- 这表明仅用“同名”或“中心接近”合并不可靠：分割碎片、类别波动、历史记录和相邻真实物品都可能存在。当前修复处理文字重叠，物理实例去重需要进一步的图像掩膜、几何和时序证据。

随后用户反馈“电视 +5、盒子 +3”，旋转时名称/数量跳变、突然显隐。这由刚加入的屏幕重叠算法触发：它每 100 ms 按文字包围框选代表，位于不同深度的物品也可能折叠在一起。因此撤掉该算法及 DOM 可见性定时器，使用上述稳定显示方式。

## 验证

`tests/test_miti_scene_adapter.py` 覆盖三维重叠与部分可见范围的重复记录、同帧独立物体、包含小物体、分组链、定向删除、时期隔离和范围缓存恢复。`tests/test_miti_semantic_labels.js` 覆盖视角输入变化时身份/文字稳定、显示模式恢复、多视图隔离、单对象更新/删除和字号限制。`tests/test_miti_frontend_install.py` 验证实际 MITI bundle 的路由与作用域，并从安装后 bundle 提取组件运行同一组渲染回归测试。这不替代真实浏览器中的 WebGL 旋转检查。
